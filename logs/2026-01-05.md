# 2026-01-05 작업 기록

## ✅ 완료된 작업

### 언론보도 기능 추가

포트폴리오 시스템에 언론보도 기능을 통합했습니다.

**구현 내용:**
- URL 입력 → OG 메타데이터 자동 파싱 (제목, 썸네일, 언론사명)
- 포트폴리오 페이지에서 언론보도 클릭 시 원본 기사로 이동

**수정 파일:**
- `prisma/schema.prisma` - Portfolio에 externalUrl 필드 추가
- `src/app/api/og-parse/route.ts` - OG 메타데이터 파싱 API (신규)
- `src/app/api/portfolio/route.ts` - externalUrl 필드 처리
- `src/app/api/portfolio/[id]/route.ts` - externalUrl 필드 처리
- `src/app/admin/portfolio/page.tsx` - 언론보도 URL 입력 UI
- `src/app/portfolio/page.tsx` - externalUrl 전달
- `src/components/portfolio/GalleryGrid.tsx` - 외부 링크 클릭 처리

**추가 파일:**
- `scripts/add-press-category.ts` - 언론보도 카테고리 추가 스크립트

## 🔧 배포 전 필요 작업

1. `pnpm add cheerio` 패키지 설치
2. `npx prisma db push` 스키마 반영
3. `npx ts-node scripts/add-press-category.ts` 카테고리 추가
4. `git push` → Vercel 자동 배포

## 🎯 사용 방법

1. 관리자 → 포트폴리오 관리
2. 카테고리에서 "언론보도" 선택
3. URL 입력 → "불러오기" 클릭
4. 제목/썸네일 자동 표시 → 저장
5. 포트폴리오 페이지에서 언론보도 카드 클릭 → 원본 기사로 이동
