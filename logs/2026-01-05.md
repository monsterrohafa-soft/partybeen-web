## 🎯 사용 방법

1. 관리자 → 포트폴리오 관리 (`/admin`)
2. 카테고리에서 **"언론보도"** 선택
3. URL 입력 → **"불러오기"** 클릭
4. 여러 이미지가 있으면 **원하는 이미지 선택**
5. **드래그로 보이는 위치 조정**
6. 저장
7. 포트폴리오 페이지에서 언론보도 카드 클릭 → 원본 기사로 이동
