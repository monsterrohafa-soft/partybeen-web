## 🎯 워터마크 사용 방법

1. 관리자 → 포트폴리오 관리 (`/admin`)
2. **"새 항목 추가"** 클릭
3. 카테고리 선택 (언론보도 제외)
4. **워터마크 로고 선택**: 없음 / 파티빈 / 쉐프의도시락
5. 이미지 업로드 → 워터마크 자동 적용!
6. 저장

## 🎯 사용 방법

1. 관리자 → 포트폴리오 관리 (`/admin`)
2. 카테고리에서 **"언론보도"** 선택
3. URL 입력 → **"불러오기"** 클릭
4. 여러 이미지가 있으면 **원하는 이미지 선택**
5. **드래그로 보이는 위치 조정**
6. 저장
7. 포트폴리오 페이지에서 언론보도 카드 클릭 → 원본 기사로 이동

### 7. 워터마크 기능 클라이언트 사이드로 재구현

서버사이드 이미지 처리(sharp, jimp)가 Vercel 서버리스에서 동작하지 않아 클라이언트 사이드 Canvas API로 재구현했습니다.

**구현 내용:**
- Canvas API를 사용하여 브라우저에서 이미지 처리
- 워터마크 로고를 흰색으로 변환 + 60% 투명도 적용
- 이미지 중앙에 30% 크기로 워터마크 배치
- 처리된 이미지를 Blob으로 변환 후 업로드

**수정 파일:**
- `src/app/admin/portfolio/page.tsx` - `applyWatermark()` 함수 추가, `handleImageUpload()` 수정

**장점:**
- 서버 의존성 없음 (Vercel 서버리스 제한 회피)
- 브라우저에서 즉시 처리
- 추가 라이브러리 불필요
