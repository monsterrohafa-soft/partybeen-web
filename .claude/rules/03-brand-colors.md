# 브랜드 컬러 지침

## 공식 컬러 팔레트

| 색상 | 코드 | 용도 |
|------|------|------|
| **피콕그린 (메인)** | `#013A46` | 배경, 푸터, 주요 버튼 |
| **피콕그린 라이트** | `#025566` | 호버, 보조 버튼 |
| **베이지** | `#FAF3ED` | 밝은 배경, 어두운 배경에서의 버튼 |
| **카카오 옐로우** | `#FEE500` | 카카오톡 버튼 |

## 사용하지 않는 색상

⚠️ **폐기된 색상**: `#c9a962` (골드) → `#025566`으로 대체됨

## Tailwind 사용

```typescript
// tailwind.config.ts에 정의됨
colors: {
  'peacock': '#013A46',
  'peacock-light': '#025566',
  // ...
}
```
